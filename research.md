## Dependencies Overview

### Core Development Dependencies

- **React**
  - For frontend development.
  - Ecosystem includes React Router, Axios (for HTTP requests), and testing libraries (Jest, React Testing Library).

- **Lightweight PHP Framework**
  - **SlimPHP**: Minimalist, works on constrained/shared hosting.

- **Database**
  - **MySQL** database management system that stores data in structured tables and supports SQL (Structured Query Language) for querying and manipulation.

### Additional Useful Dependencies

- **dotenv**: Manage environment variables.
- **Composer**: PHP dependency manager.
- **Nodemon**: Auto-reload for local Node.js utilities.
- **http-server** (Node): Simple static/mock server.
- **Requestly**: Export/import rulesets for mocking.
